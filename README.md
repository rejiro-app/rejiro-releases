# Re:JIRO

太鼓さん次郎との互換性を重視した、Windows向けの太鼓譜シミュレーターです。
段位モード、フリー練習、テーマカスタマイズ、動画背景などに対応しています。

## ダウンロード

[最新バージョンをダウンロード](https://github.com/rejiro-app/rejiro-releases/releases/latest)

対応OS：Windows 10 / Windows 11

ZIPをすべて展開し、フォルダー内の `ReJIRO.exe` を起動してください。付属ファイルも必要なため、EXEだけを移動しないでください。
更新時はアプリを終了し、既存の設定・プレイ記録・楽曲などの保存データを残してください。

フォルダー整理版では、`ReJIRO.exe` が起動用、`app` がアプリ本体、`data` が設定・成績・画像・ログの保存先です。譜面は `song`、太鼓SEは `snd`、説明書は `docs` に格納します。`app` はフォルダー一式が必要です。
旧構成からの引き継ぎ時は、内容を照合して保存データを移し、旧ファイルを `data/backups` に残します。引き継ぎ中は旧バージョンを起動しないでください。

利用前に [利用規約](TERMS.md) をご確認ください。今回の変更は [1.9のパッチノート](PATCH-NOTES.md) を参照してください。

## 1.9のフォルダ構成

```text
ReJIRO/
  ReJIRO.exe  起動用
  app/        アプリ本体（フォルダ一式が必要）
  data/       設定・成績・履歴・リプレイ・画像・ログ
  song/       譜面
  snd/        太鼓SE（任意のWAVを配置）
  docs/       説明書・パッチノート
```

- 最上位の `ReJIRO.exe` を起動してください。`app` 内のEXEを単独で移動したり、DLL・`resources`・`locales` などを削除すると起動できません。
- 初回起動時の自己展開はありません。ZIPは必ずすべて展開してください。
- 太鼓SEのWAVは同梱していません。使用中の `snd` を残すか、対応するWAVを配置してください。WAVがない場合は代替SEを使用します。

## 更新方法

1. Re:JIROを終了し、使用中のフォルダ全体をバックアップします。
2. ZIPの中身を、現在の `ReJIRO.exe` と同じ場所へ展開します。起動用EXE・`app`・`docs` は新版を使用し、既存の `data`・`song`・`snd` は削除しないでください。
3. 最上位の `ReJIRO.exe` を起動します。旧構成の場合は、設定・成績・履歴・画像などを内容照合して `data` へ引き継ぎ、元のファイルを `data/backups` に保存します。移行中は旧版を同時に起動しないでください。

旧構成の保存データと `data` の両方がある場合は、上書き防止のため移行を止めます。移行エラーが出ても保存データを削除せず、バックアップを保ったまま配置を確認してください。
楽曲フォルダを整理・移動する場合は、アプリの引き継ぎ機能を使用してください。外部アプリでの移動はジャケットなどの関連付けが変わる場合があります。
