# Re:JIRO

太鼓さん次郎との互換性を重視した、Windows向けの太鼓譜シミュレーターです。
2Pプレイ、段位モード、フリー練習、テーマカスタマイズ、動画背景に対応しています。
v2.0には、TJA Maker β・Music Player・Chart Review βも含まれます。

## ダウンロード

[最新バージョンをダウンロード](https://github.com/rejiro-app/rejiro-releases/releases/latest)

このパッケージのバージョン：2.0.1

v2.0.1では、チュートリアル・フォント保存・キャッシュ管理を追加し、操作と譜面互換を改善しました。外部通信を許可している場合は、v2.0.0からも更新機能を利用できます。

対応OS：Windows 10 / Windows 11（64bit）

ZIPをすべて展開し、フォルダー内の `ReJIRO.exe` を起動してください。付属ファイルも必要なため、EXEだけを移動しないでください。
更新時はアプリを終了し、既存の設定・プレイ記録・楽曲などの保存データを残してください。

フォルダー整理版では、`ReJIRO.exe` が起動用、`app` がアプリ本体、`updater` が更新処理用、`data` が設定・成績・画像・ログの保存先です。譜面は `song`、太鼓SEは `snd`、説明書は `docs` に格納します。付属フォルダーは一式で残してください。
旧構成からの引き継ぎ時は、内容を照合して保存データを移し、旧ファイルを `data/backups` に残します。引き継ぎ中は旧バージョンを起動しないでください。

利用前に [利用規約](TERMS.md) をご確認ください。今回の変更は [v2.0.1のパッチノート](PATCH-NOTES.md) を参照してください。

## 初めて起動する場合

1. ZIPをすべて展開し、展開先の最上位にある `ReJIRO.exe` を起動します。ZIP内のEXEを直接開かないでください。
   初回は外部通信の許可を確認します。未選択・「許可しない」の場合は外部通信を止め、ローカルの譜面・音源でプレイできます。後から「その他 → 通信とプライバシー」で変更できます。
2. 初回のチュートリアルで、譜面フォルダの準備・ドンとカッ・実際の選曲画面を確認できます。「設定 → その他 → チュートリアル」から再表示できます。同梱デモでも動作を確認できます。自分の譜面は「設定 → その他 → TJAフォルダ」から登録します。TJAが参照する音源・画像などは元の配置を保ってください。
3. 曲と難易度を選び、「演奏開始」でプレイします。アプリ一覧から譜面編集・音楽再生・評価・テーマ編集を開けます。

設定や成績を保存できる、書き込み可能なフォルダへ展開してください。`Program Files`など管理者権限が必要な場所は避けてください。

## フォルダ構成

```text
ReJIRO/
  ReJIRO.exe  起動用
  app/        アプリ本体（フォルダ一式が必要）
  updater/    更新用EXEと付属設定ファイル
  data/       設定・成績・履歴・リプレイ・画像・ログ
  song/       譜面
  snd/        太鼓SE（任意のWAVを配置）
  TJA Maker Projects/  保存したプロジェクト（初回保存時に作成）
  docs/       説明書・パッチノート
```

- 最上位の `ReJIRO.exe` を起動してください。`app` 内のEXEを単独で移動したり、DLL・`resources`・`locales` などを削除すると起動できません。
- 初回起動時の自己展開はありません。ZIPは必ずすべて展開してください。
- 太鼓SEのWAVは同梱していません。使用中の `snd` を残すか、対応するWAVを配置してください。WAVがない場合は代替SEを使用します。

## 更新方法

「設定 → その他 → アップデートの確認」から更新を確認できます。初期設定は「通知のみ」で、新しい正式版があれば起動後にポップアップで案内します。「自動更新」を選んだ場合は待機中に取得し、次回起動時に適用します。設定ボタンの「更新」バッジも目印になります。詳しくは [更新の確認と自動更新](updates.md) を参照してください。

外部通信を許可しない場合は、通知・自動の設定でも外部への更新確認・取得を行いません。通信ON時は、現在のテーマ・設定で必要なフォントを自動取得して保存します。新しく取得が必要なフォントを選ぶ際の確認は維持しています。保存済みフォントは通信OFFでも再利用し、未保存なら代替フォントを使います。[通信とプライバシー](network-privacy.md) もご確認ください。

更新機能のない旧版からの初回更新や、手動で更新する場合は次の手順を使用してください。

1. Re:JIROを終了し、使用中のフォルダ全体をバックアップします。
2. 新しいZIPを別の作業フォルダへすべて展開します。展開した `ReJIRO.exe`・`app`・`updater`・`docs` を使用中の同名のものと入れ替えます。**既存の `data`・`song`・`snd`・`TJA Maker Projects` は削除・置き換えしないでください。** 古い本体・更新用ファイル・説明書も退避しておくと元へ戻せます。
3. 使用中のフォルダの最上位にある `ReJIRO.exe` を起動します。1.9.4の保存データは引き継げます。成績移行の確認が出た場合、既存の成績を維持するには「既存データを引き継ぐ」を選びます。旧構成の場合は、設定・成績・履歴・画像などを内容照合して `data` へ引き継ぎ、元のファイルを `data/backups` に保存します。移行中は旧版を同時に起動しないでください。

旧構成の保存データと `data` の両方がある場合は、上書き防止のため移行を止めます。移行エラーが出ても保存データを削除せず、バックアップを保ったまま配置を確認してください。
外部に登録した譜面・音源や任意の保存先のプロジェクトも、更新・移動前に別途バックアップしてください。楽曲の移動後に複数候補があるなど、安全に特定できない場合は自動引き継ぎしないことがあります。

復元方法と自動バックアップの対象範囲は [バックアップと復元](backup-restore.md) を参照してください。自動バックアップだけで本体フォルダ全体を復元できるとは限りません。

## v2.0の主な操作

| 操作 | 既定のキー・入口 |
| --- | --- |
| 1P／2P切り替え | 選曲画面でF5 |
| AUTO切り替え | F1。2PではOFF／1P／2P／両方を切り替え |
| 演奏オプション | 選曲画面でF2。2Pでは設定するプレイヤーを選択 |
| 太鼓1P | ドン：F・J、カッ：D・K |
| 太鼓2P | ドン：V・N、カッ：C・M |
| ポーズ／フリー練習 | 演奏中にEsc／Q |
| リプレイ保存 | 対応するリザルトでF9。再生は「アプリ → リプレイ再生」 |

キーは「設定 → 操作」で変更できます。2Pの難易度は同じカード列で選び、選択中の1P・2P表示を確認してください。別TJAでのプレイは「演奏開始」右隣のメニューから選べます。共通の音源は1P側を使用し、開始前にOFFSETの合わせ方を選びます。

## 追加アプリ

- **TJA Maker β**：新規作成・TJAを開く・普段の選曲画面から選ぶ入口があります。数字キーでの音符配置、TJAテキスト編集、試奏に対応します。プロジェクト保存では音源・ジャケットもまとめて `TJA Maker Projects` へ保存します。元TJAへの上書き保存とプロジェクト保存は別です。β版のため、編集前の譜面と素材はバックアップしてください。
- **Music Player**：登録譜面の音源をフォルダ・ジャケット・再生待ち・プレイリストから再生します。音源は先頭から再生し、演奏用のOFFSETは使いません。別窓やWindowsのタスクバープレビューからも操作できます。演奏・練習・リプレイ開始時は一時停止します。
- **Chart Review β**：必ず別ウィンドウで開き、譜面の評価・感想を保存します。操作SEと音量はアプリ内の設定から変更できます。β版のため、評価データもバックアップに含めてください。
- **Theme Studio**：配置・色・フォント・画像を編集し、自作テーマの保存・読み込みや `.rejirothm` のインポート・エクスポートができます。PC固有のフォントはテーマファイルに含まれません。

同梱のDefault・Arcade・Minimal・Terminal・Glassは、1P・2P・段位の既定配置を更新しています。保存済みの編集内容は自動で上書きしません。更新後の既定値を使う場合は、必要に応じてテーマを書き出してから、対象テーマの「既定値に戻す」を使用してください。

軽量テーマ「Minimal Max」も追加しました。フラットな太鼓と基本的な演奏情報を残し、画像・動画背景、波形、スペクトラム、粒子演出などを省いた構成です。テーマ一覧から選択できます。Montserratは本体へ同梱し、外部のWebフォントの応答を待たずに起動します。

## 制限と困ったとき

- **段位モードは1P専用**です。2Pでは利用できません。TJA MakerとChart Reviewはβ版です。
- 次郎とのすべての特殊譜面・入力・描画の完全一致を保証するものではありません。
- 旧リプレイは、対応形式と元の譜面・音源がそろい、再生前の照合に通ったものを再生できます。バージョンが違うだけでは拒否しませんが、すべての記録の互換を保証するものではありません。
- 保存データを読み込めない案内が出た場合、元のファイルを削除せず終了し、[バックアップと復元](backup-restore.md)を確認してください。
- 外部譜面フォルダを外した・接続できない場合は、保存設定を初期化する前に登録先やドライブの接続を確認してください。
