# Re:JIRO

太鼓さん次郎との互換性を重視した、Windows向けの太鼓譜シミュレーターです。1P・2Pプレイ、コース・段位、フリー練習、譜面編集、テーマのカスタマイズに対応しています。

**対応OS：Windows 10 / Windows 11（64bit）**

## ダウンロード

**[最新版のZIPをダウンロード](https://github.com/rejiro-app/rejiro-releases/releases/latest)**

[機能一覧・スクリーンショット](FEATURES.md) | [現在のパッチノート](PATCH-NOTES.md)

## はじめ方

1. 配布ページのAssetsから `ReJIRO-v...-windows.zip` をダウンロードし、すべて展開します。「Source code」のZIPではありません。
2. 展開先の最上位にある `ReJIRO.exe` を起動します。
3. チュートリアルに沿って準備します。自分の譜面は「設定 → その他 → TJAフォルダ」から登録できます。
4. 曲と難易度を選び、「演奏開始」でプレイします。

**ZIP内から直接起動したり、EXEだけを移動したりしないでください。** 付属フォルダも必要です。設定や成績を保存できる場所へ展開し、`Program Files`など書き込みが制限される場所は避けてください。

初回起動時に外部通信の許可を確認します。許可しなくても、ローカルの譜面・音源でプレイできます。詳しくは[通信とプライバシー](network-privacy.md)をご確認ください。

## 更新するとき

「設定 → その他 → アップデートの確認」から更新できます。外部通信の許可が必要です。初期設定は「通知のみ」で、自動更新を選ぶと次回起動時に適用します。

- 更新前にアプリを終了し、使用中のフォルダ全体をバックアップしてください。
- 手動更新では、保存データの `data`・`song`・`snd`・`TJA Maker Projects` を削除・上書きしないでください。
