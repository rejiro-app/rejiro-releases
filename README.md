# Re:JIRO

Re:JIROの公式配布用リポジトリです。
アプリ本体のソースコードは公開していません。

## ダウンロード

[最新リリース](https://github.com/rejiro-app/rejiro-releases/releases/latest)から `ReJIRO-v1.8.1-windows.zip` を入手し、展開したフォルダー内の `ReJIRO.exe` を起動してください。
ZIPには「BAD ACCESS (FROM A MOE MAID)」の譜面・OGG音源・ジャケットを同梱しています。
1.8.1は、起動時の自己展開が不要なフォルダー形式です。ZIPをすべて展開し、`ReJIRO.exe` とDLL・`resources`・`locales` などの付属ファイルを同じ場所に保ってください。EXEだけでは起動できません。別の場所から起動する場合は、EXEのショートカットを使用してください。
更新時はRe:JIROを終了し、ZIP内のアプリファイルを一式更新してください。既存の `settings.json`、`user-data`、楽曲、SE、画像などの保存データは削除しないでください。WAVは同梱していません。
利用前に [利用規約](TERMS.md) をご確認ください。

## 独立入力（実験的機能）

設定 → その他 → 実験的機能 → 「入力・判定を独立して処理（通常1P・手動演奏）」で有効にできます。初期状態はOFFです。

通常1Pの手動演奏と、重複しない英字4キーが対象です。コース・段位・オート・フリー練習・途中開始・非対応キーでは従来処理を使います。
SEも独立して処理する場合は、EXE横の `snd` フォルダーに対応WAVを用意し、オーディオの「Windows音声で太鼓SEを再生」をONにしてください。出力方式はWaveOut／WASAPI（試験）から選択できます。既定はWaveOutで、WAVがない場合は従来の代替SEを使用します。
WASAPIは太鼓SE用の試験機能です。楽曲の出力方式や判定幅は変更せず、機器によってはWaveOutより遅くなる場合もあります。
これは画面処理待ちの影響を抑えるための試験機能です。全環境での遅延短縮量や、完全な互換性を保証するものではありません。問題があればOFFに戻してください。

## Re:JIROについて

太鼓さん次郎との互換性を重視した太鼓譜シミュレーターです。
段位モード、フリー練習、テーマカスタマイズ、動画背景などに対応しています。

## 動作環境

- 必須OS：Windows 10 / Windows 11
- 推奨CPU：Intel Core i3 第8世代以上 / AMD Ryzen 3 第2世代以上
- 推奨GPU：DirectX 11 または Vulkan 対応GPU（外部GPU推奨）
- 推奨VRAM：1GB以上
- 推奨メモリ：8GB以上

※推奨環境は未検証です。あくまで快適に動作できるだろうという目安だとご判断ください。

Re:JIROの開発には、Codexなどの生成AIを活用しています。
